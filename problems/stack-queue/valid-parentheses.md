# 有效的括号 LeetCode 20

**难度**：简单 ｜ **分类**：栈与队列 ｜ **标签**：栈

## 题目描述

给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 s,判断字符串是否有效。
有效字符串需满足:左括号必须用相同类型的右括号闭合;左括号必须以正确的顺序闭合;每个右括号都有一个对应的同类型的左括号。

**示例**
```
输入: s = "([)]"      输出: false
输入: s = "()[]{}"    输出: true
输入: s = "{[]}"      输出: true
```

## 思路与图解

遇到**左括号入栈**,遇到**右括号**时检查栈顶是否为匹配的左括号(是则弹出,否则非法);遍历结束栈应为空。

```
s = "{ [ ] ( ) }"
栈:  ↓ 入栈         ↓ 匹配弹出      ↓ 匹配弹出
   {        {        {             {        {}  → 栈空 ✓
   [        ]        [ 弹出
   读 { 压栈        读 [ 压栈       读 ] 弹出    读 ( 压栈 读 ) 弹出  读 } 弹出

匹配规则(遇到右括号看栈顶):
  ) 需要栈顶 (     ] 需要栈顶 [     } 需要栈顶 {
```

**三种非法情况**全部可由栈处理:
1. 右括号时栈空 → `"]"` 开头之类;
2. 栈顶与当前右括号不匹配 → `"([)]"`;
3. 遍历完栈非空 → `"(()"`。

## 复杂度

- 时间:O(n)
- 空间:O(n),最坏全是左括号

## 参考代码

### C++

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;
        for (char c : s) {
            if (c == '(' || c == '[' || c == '{') st.push(c);
            else {
                if (st.empty()) return false;
                char t = st.top();
                if ((c == ')' && t != '(') || (c == ']' && t != '[') || (c == '}' && t != '{')) return false;
                st.pop();
            }
        }
        return st.empty();
    }
};
```

### Python

```python
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {')': '(', ']': '[', '}': '{'}
        st = []
        for c in s:
            if c in pairs:
                if not st or st.pop() != pairs[c]:
                    return False
            else:
                st.append(c)
        return not st
```

## 小结

- **括号匹配是栈的经典应用**(编译器语法检查同理)。
- 小技巧:右括号→左括号用字典映射,代码更简洁。
