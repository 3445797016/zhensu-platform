# 只出现一次的数字 LeetCode 136

**难度**：简单 ｜ **分类**：位运算 ｜ **标签**：异或

## 题目描述

给你一个非空整数数组 nums,除了某个元素只出现一次以外,其余每个元素均出现两次。找出那个只出现了一次的元素。
要求:你的算法应该具有线性时间复杂度。不使用额外空间来实现。

**示例**
```
输入: nums = [4,1,2,1,2]
输出: 4
```

## 思路与图解

利用异或运算三条性质:
- `a ^ a = 0`(相同抵消)
- `a ^ 0 = a`
- 交换律/结合律

把数组全部异或一遍,**成对的元素全部抵消成 0,剩下的就是落单的那个**。

```
nums = [4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1^1) ^ (2^2)       交换结合
= 4 ^ 0 ^ 0
= 4 ✓

图解(把成对的看成一对对抵消):
  4, [1,1]抵消→0, [2,2]抵消→0 → 只剩 4
```

不需要哈希表(O(n) 空间)也不需要排序(O(n log n)),一趟遍历、一个变量,同时满足时间和空间要求。

## 复杂度

- 时间:O(n)
- 空间:O(1)

## 参考代码

### C++

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for (int x : nums) ans ^= x;      // 异或抵消成对的
        return ans;
    }
};
```

### Python

```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0
        for x in nums:
            ans ^= x
        return ans
```

## 小结

- 异或是位运算中"原地去重"的利器,记住 `a^a=0、a^0=a`。
- 进阶:137 只出现一次的数字 II(每个数出现三次 → 按位统计 %3)、260 只出现一次的数字 III(两个落单数 → 分组异或)。
- 适用前提:**其余元素恰出现偶数次**。
