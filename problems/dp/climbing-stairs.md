# 爬楼梯 LeetCode 70

**难度**：简单 ｜ **分类**：动态规划 ｜ **标签**：DP

## 题目描述

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。
每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢?

**示例**
```
输入: n = 3
输出: 3
解释: 三种: 1+1+1、1+2、2+1
```

## 思路与图解

**DP 五步走**:
1. `dp[i]` = 爬到第 i 阶的方法数;
2. 递推:最后一步要么从 i-1 跨 1 阶、要么从 i-2 跨 2 阶 → `dp[i] = dp[i-1] + dp[i-2]`(斐波那契);
3. 初始化 `dp[1]=1, dp[2]=2`;
4. 从 3 到 n 顺序递推;
5. 返回 dp[n]。

```
台阶:  0   1   2   3   4
方法:  1   1   2   3   5     (dp[n]=dp[n-1]+dp[n-2])

到第4阶的路径可看作:
  到第3阶的所有路径 +1 步      → dp[3]=3 种
  到第2阶的所有路径 +2 步      → dp[2]=2 种
  合计 5 种 ✓
```

**状态压缩**:递推只用前两个值,可用两个变量滚动,空间 O(1)。

## 复杂度

- 时间:O(n)
- 空间:O(1)(滚动)或 O(n)(数组)

## 参考代码

### C++

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) return n;
        int a = 1, b = 2;                  // dp[i-2], dp[i-1]
        for (int i = 3; i <= n; i++) {
            int c = a + b;
            a = b;
            b = c;
        }
        return b;
    }
};
```

### Python

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        a, b = 1, 2
        for _ in range(3, n + 1):
            a, b = b, a + b
        return b
```

## 小结

- 爬楼梯是 DP 入门第一题,递推 `f(n)=f(n-1)+f(n-2)`。
- 变体:一步可跨 1..m 阶 → `dp[i]=sum(dp[i-j])`(完全背包思想);746 使用最小花费爬楼梯(加 cost)。
